[English](./README.md) | **中文**

使用 DiceBear，你可以在短时间内为你的项目创建出色的头像。
无论你是在寻找抽象形状还是精心设计的角色，你都能在我们丰富的头像风格中找到合适的选择。
无论你想如何使用这些头像，DiceBear 都能提供正确的解决方案！

除了纯随机头像，你还可以为用户身份创建确定性头像。
通过内置的 PRNG，你可以基于一个种子（seed）反复生成相同的头像。
当然，个性化头像同样可以实现！只需使用每种头像风格提供的众多选项即可。

得益于 JavaScript 库、HTTP API、CLI、Figma 插件和在线演练场，你的下一个头像触手可及！
